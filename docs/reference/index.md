# Reference AI Architecture Pack

This directory contains the reference architecture split into function-specific documents.

These documents are target-state enterprise reference material for retail AI systems in a Databricks-and-AWS ecosystem. They do not define shipped application behavior, deployment commitments, or current release evidence; use the [product guide](../product/index.md), [architecture guide](../architecture/index.md), and [quality guide](../quality/index.md) for those authorities.
