# Product Guide

## Scope

This section owns business outcomes, use cases, constraints, and success measures. It does not define runtime implementation or release evidence; use [architecture](../architecture/README.md), [quality](../quality/README.md), and [operations](../operations/README.md) for those concerns.

## Primary Document

- [Business specifications](business-specs.md): business goals, stakeholders, functional expectations, and success criteria.

## Current Capability Boundary

The deployed platform supports governed tool-backed requests across sales, product knowledge, Flink support, CDI, and Lakebase operational data. Agent delegation is bounded app-auth task processing, not an unbounded mailbox or autonomous collaboration framework. Proposed workflows and expanded domain coverage require their own registry, policy, quality, and operational evidence.
